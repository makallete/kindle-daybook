# Kindle Daybook

## Platform and users
A public bilingual project guide and a self-hosted e-ink application. People with an old Kindle should understand prerequisites, check compatibility and follow setup without exposing private calendars. Turkish and English documentation and device interface; the operating timezone remains Europe/Istanbul.

## Product truth
The original application runs on a 90D4 Paperwhite 2, firmware 5.12.2.2. The generalized alpha installer has not been installed on a second clean device. It requires an already working jailbreak, scriptlet integration and key-based root SSH. These prerequisites are upstream and not bundled. Google traffic is optional; no universal free/no-card promise. Each user owns their Cloudflare deployment and credentials. Default name Daybook is configurable; author signature only at the website footer.

## Scope
MIT original sources, source ZIP, upstream credits, compatibility check, download, bilingual step-by-step guide, fictional preview, configurable name, optional commute, install/uninstall scripts. No Amazon binaries, personal books/photos, private keys, addresses or calendar data. Optional Home/Store customization builds verified patches locally; it is a separate reversible action.

## Visual authority
Extend the existing app's monochrome paper/ink, self-hosted Manrope and large type. The site is a readable, restrained project manual with a device preview; no new brand world or comp round. Code-led continuation of the established visual identity.

## Optional photo screensaver guidance
After the main app setup, a closed native disclosure at the bottom of the page offers “Kindle ekran koruyucu özelleştirme” / its English equivalent. Three short actions tell the user to upload a photo to the same Codex or Claude Code chat, request a preview, then approve applying it and check the result from Home with the power button. The main prompt section keeps only menu-icon/Home-cover customization; its raw screensaver guide link is removed. There is no website uploader and private photos are never published.

Prompt item 9 points the agent to the local `docs/SCREENSAVER.tr.md` or `docs/SCREENSAVER.en.md` source. The guide recipe itself remains unchanged: it is an agent-guided, verified-PW2 workflow with original-file backup and restore, not an automatic screensaver installer. Public source is under GitHub author `makallete`; the site is https://kindle-daybook-makallete.netlify.app.

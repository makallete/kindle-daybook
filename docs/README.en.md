# Kindle Daybook

[English setup](SETUP.en.md) · [Türkçe](../README.md)

Give an old Kindle a practical new job: your calendar, weather and optional traffic-aware commute. Choose your own display name. The Cloudflare Worker runs in your own account; your computer can be switched off.

**v0.1.0-alpha.** The original app was verified on a Paperwhite 2 (2013), firmware 5.12.2.2, variant 90D4. The generalized installer has not yet been tested on a second clean device. Other models are not supported by this alpha installer.

- Personal and shared iCal feeds, recurrences, exceptions and multi-day events.
- Selectable days, six-event pages and automatic return after 100 seconds.
- Three-day Open-Meteo forecast, configurable city and coordinates.
- Optional Google Routes commute with real road geometry, fastest returned traffic-aware alternative and a 30-second manual-direction timeout.
- Custom display name, Turkish or English interface (APP_LANGUAGE), with Europe/Istanbul time.
- Mesquite fullscreen and physical-button exit on the validated device.

Start with the [English setup guide](SETUP.en.md). Optional native Home/Store patches are built locally from verified factory originals; see [the native guide](NATIVE.en.md). Books, personal screensavers and Amazon system files are not distributed. The upstream jailbreak is not ours and is not bundled.

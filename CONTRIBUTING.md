# Contributing / Katkı

English and Turkish contributions are welcome. Start with an issue for a new device/firmware. Keep device-specific patches separate from the core display.

1. Run `cd worker && npm ci && npm test`.
2. Use fictional calendar/location data in fixtures and screenshots.
3. Include model/firmware and whether the change was tested on a physical device.
4. Never include iCal private URLs, API keys, SSH keys, real events or private display links.
5. Update both setup guides when behavior changes.

Only the original PW2 application has been device-verified. Do not mark another device supported without evidence. A test passing on Node does not establish Mesquite compatibility.

Türkçe hata bildirimleri ve katkılar kabul edilir. Yeni cihaz/sürüm desteğinde önce issue aç; cihaz bilgilerini ve gerçek cihaz test sonucunu ekle. Gizli bağlantı veya anahtar paylaşma.
